Politique de confidentialité

Accès et usage

Avec l’autorisation drive.file, Pluritual Recette Drive crée et lit les fichiers de sauvegarde chiffrés et leurs métadonnées dans le dossier dédié. L’outil contrôle l’espace disponible pour arrêter la copie avant saturation. Il n’utilise pas les autres fichiers Drive, les messages, les contacts ou les données de profil Google.

Stockage et prestataires

Les archives chiffrées contenant des données de recette sont conservées dans le Drive privé du compte qui a donné son accord. L’accès hors ligne est conservé dans les secrets du dépôt GitHub privé qui exécute la sauvegarde. Le service de tâches GitHub communique directement avec Google Drive. Les journaux techniques indiquent l’état de la tâche et les contrôles d’intégrité. Les données Google ne sont utilisées ni pour la publicité ni pour entraîner des modèles et ne sont pas vendues.

L’usage des informations reçues via les API Google respecte le règlement de Google sur les données utilisateur, y compris ses exigences d’utilisation limitée.

Révocation et suppression

Le titulaire du compte peut retirer l’accès dans les connexions de son compte Google. Les sauvegardes restent dans son Drive jusqu’à leur suppression par le titulaire. Pour toute question, utiliser le contact d’assistance indiqué dans l’écran de consentement Google.
